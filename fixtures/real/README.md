| File | Origin | License |
|---|---|---|
| `box.solidcraft` | Generated by a SolidCraft release on 2026-10-22 with `solid.box` (40 × 30 × 20 mm, body `Box`) | CC0-1.0 |
| `box.lean.solidcraft` | The same file with `cache/*` removed (`zip -d`) | CC0-1.0 |

Regenerate the container:

```sh
cat > /tmp/make-box.json <<'JSON'
{"commands":[{"command":"solid.box","params":{"length":40,"width":30,"height":20,"body_name":"Box"}}]}
JSON
solidcraft-cli run /tmp/make-box.json --save box.solidcraft
cp box.solidcraft box.lean.solidcraft
zip -d box.lean.solidcraft 'cache/*'
```

These are real documents: the CLI can evaluate and render them. They are intentionally tiny so they
can live in tests and git.
